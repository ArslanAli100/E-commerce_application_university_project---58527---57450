# E-Commerce_flutter_application_university_project

Sportswear E-Commerce Mobile Application

Overview

This is a comprehensive e-commerce mobile application designed for selling sportswear. Developed using Flutter, this app offers a seamless and engaging shopping experience for users. It includes a variety of features such as product listings, detailed product descriptions, a shopping cart, a favorites list and authentication with email.

Features:

1. User Authentication: Secure sign-in functionality.
2. Product Listings: Browse through a wide range of sportswear products.
3. Filter: Easily find products with filter options.
4. Product Details: View detailed information, images, and reviews for each product.
5. Shopping Cart: Add products to the cart and manage them.
6. Favorites: Save products to a favorites list for future purchases.
7. User Profile: Manage your profile.

Technology Stack:

Flutter: Framework for building the application.
Dart: Programming language used for Flutter development.
Firebase: Backend services including authentication, database, and storage.
Provider: State management.

Create a Firebase project at Firebase Console.
Add an Android/iOS app to your Firebase project.
Download the google-services.json (for Android) or GoogleService-Info.plist (for iOS) and place them in the respective directories.
Follow the instructions to add Firebase to your Flutter project: FlutterFire Overview.

Run the app:
Copy code
flutter run
